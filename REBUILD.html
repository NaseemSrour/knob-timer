🎛️ Knob Timer — Maintenance Guide

How to rebuild the app after a code change, and how to set the alarm sound.

🔨 Rebuild after a code change

  1. Edit knob_timer.py and save your changes.
  2. Open PowerShell in the project folder (C:\Users\Naseem\Projects\knob-timer).
  3. Run the one build command:
.\venv\Scripts\pyinstaller.exe KnobTimer.spec --noconfirm
  1. Grab the fresh dist\KnobTimer\ folder — ship the whole folder, not just the exe.
🛡️ The build reads KnobTimer.spec — keep that file, it's the recipe. It builds a one-folder bundle with UPX off so Windows Smart App Control lets it run (the old --onefile + UPX build got blocked). Don't switch back to onefile. The temporary build\ folder is safe to delete.

🔔 Set the alarm sound

  1. Get an audio file — .mp3, .wav, or .ogg.
  2. Put it in the same folder as KnobTimer.exe.
  3. Name it alarm.mp3 (the default the app looks for), or open config.json and point "audio_file_path" at your file.
  4. You can also just press S in the app and pick the file there.

The folder you ship should look like this:

📁 KnobTimer
 ├── KnobTimer.exe     ← the app
 ├── _internal\        ← its runtime — must stay beside the exe
 ├── alarm.mp3         ← your sound (next to the exe)
 └── config.json        ← created automatically on first run
💡 No sound file present? The app still runs and falls back to a system beep — nothing breaks.

🚚 Deploying on another PC

  1. Copy the zip over, then unblock it before extracting: right-click the .zip → Properties → tick ☑ Unblock → Apply. Now extract.
  2. Open the folder and double-click KnobTimer.exe.
⚠️ Skip the Unblock and Windows Smart App Control blocks the app — most obviously when you launch it from a desktop shortcut. Already extracted without unblocking? Run once in PowerShell: 
Get-ChildItem "C:\path\to\KnobTimer" -Recurse | Unblock-File
Making a shortcut? Set its “Start in” field to the KnobTimer folder so the exe finds _internal\.
