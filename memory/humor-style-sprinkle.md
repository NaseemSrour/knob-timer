For READMEs, docs, and UI copy the user likes an "intelligent, sprinkle-not-sentences" humor style: clean professional **English** that stands alone, lightly seasoned with **Lebanese Arabizi keywords** and short deadpan asides (yalla, khalas, bas, habibi, ma3lesh, wallah, 3a zaw2ak, karam, "mitl l-dawle"). One sprinkle per paragraph, never a full Arabizi sentence, never blocking comprehension. Intelligent/self-aware over slapstick; technically honest; safe topics only (electricity/moteur, traffic, our own code fighting back) — no politics/sect/religion.

**Why:** The user explicitly rejected "American funny" (zany, all-English) and full-Arabizi paragraphs; "sprinkle, not sentences" is exactly what they wanted.

**How to apply:** Default to this voice when writing docs/marketing copy for this user. The full portable guide is in `humor-style-guide.txt` at the repo root (meant to be pasted into other projects' agents). Locale is Lebanese but the discipline generalizes.
